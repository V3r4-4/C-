# Designs for Projects:

* ## CGPA Calculator
    * **Input**
      1. Number of Courses
      2. Grade to each Course
      3. Credits

    * **Compute**
      1. Total Semester Credit Hours
      2. Quality Points
      3. All credit hours
      4. GPA
      5. CGPA
      6. CGPA grade

    * **Output**
      1. GPA
      2. CGPA
      3. CGPA grade(e.g First class Honors)
